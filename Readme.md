# MetaLens - File Metadata Extractor

MetaLens is a browser-based file metadata extraction application.

Users can upload image or PDF files and inspect metadata directly in the browser.

### Features

- Image file support
- PDF file support
- Drag and drop upload
- File name
- File size
- MIME type
- Last modified date
- Image dimensions
- Image aspect ratio
- Image megapixel calculation
- EXIF camera manufacturer
- Camera model
- Date taken
- Exposure information
- ISO information
- Focal length
- GPS latitude and longitude
- PDF page count
- PDF title
- PDF author
- PDF creator and producer information

### Technologies Used

- HTML
- CSS
- JavaScript
- Browser File API
- FileReader API
- EXIF.js
- PDF.js

## Setup Instructions

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a browser.
4. Upload an image or PDF.
5. View the extracted metadata.

A local development server such as VS Code Live Server can also be used.

## Privacy

File processing happens inside the browser. The application does not upload files to a custom backend server.
